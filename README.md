# 🇷🇺 Russe Trainer — extension Chrome

Transforme les pages web en russe pour apprendre en naviguant.

## Installation
1. Ouvre Chrome → `chrome://extensions`
2. Active **Mode développeur** (en haut à droite)
3. Clique **Charger l'extension non empaquetée**
4. Sélectionne le dossier `russe-trainer`
5. Épingle l'icône, clique dessus, active et règle les niveaux

## Fonctionnement
- **Lettres** : remplace des lettres/digrammes latins par la lettre cyrillique qui *sonne* pareil (`a→а`, `ch→ш`, `ou→у`…).
- **Mots** : traduit les mots français connus (`chat→кот`, `merci→спасибо`…).
- **Phrases** : traduit des expressions entières (`au revoir→до свидания`…).
- **Pourcentage** : proportion du texte transformé (mets 10 % pour débuter, 100 % pour te tester).
- **Bulle** : passe la souris sur un mot orange (ou maintiens `Alt` selon le réglage) → le mot d'origine + la prononciation s'affichent.

## Personnaliser
Ajoute tes propres mots/phrases dans `dico.js` (`WORDS`, `PHRASES`).
Recharge l'extension puis la page.

> Prototype pédagogique : les traductions couvrent le vocabulaire courant, pas toute la langue.
